# COMS Desktop

Десктопное приложение COMS на Electron. Загружает боевой веб-клиент,
но добавляет то, чего браузер дать не может.

## Зачем

- **Обход блокировок.** Приложение при запуске проверяет оба входа
  (`voyage-coms.ru` через Cloudflare и `communications.voyage-community.ru`
  напрямую) и открывает работающий. У провайдеров, которые режут один из путей,
  белого экрана больше не будет.
- **Демонстрация экрана** со своим выбором окна/экрана + системный звук.
- **Камера и микрофон** без повторных запросов разрешений.
- **Трей**: закрытие окна не обрывает звонок, приложение остаётся в трее.
- **Сессия сохраняется** между запусками (вход и «запомнить устройство» не слетают).

## Разработка

```bash
npm install
npm start
```

## Сборка установщика (Windows)

```bash
npm run build:win
```

Результат: `release/COMS-Setup-<версия>.exe` + `latest.yml` (нужен для автообновления).

## Выпуск новой версии

1. Поднять `version` в `package.json`
2. `npm run build:win`
3. `node ../deploy/deploy-desktop.js` — выкладывает сборку на сервер

Клиенты проверяют обновления при запуске и раз в 6 часов. Когда обновление
скачано, приложение предлагает перезапуститься; **во время звонка диалог не
показывается** — предложение откладывается до конца разговора. Если отложить,
обновление установится при следующем выходе.

Раздача идёт с `/downloads/` на обоих доменах, и адрес обновлений выбирается
тем же перебором, что и сам сервис — блокировка одного домена не ломает
обновления.

## Самопроверка

```bash
COMS_SELFTEST=1 npm start                                  # обычный запуск
COMS_SELFTEST=1 COMS_TEST_BLOCK=voyage-coms.ru npm start   # имитация блокировки провайдером
```

Печатает выбранный адрес, факт загрузки приложения и число источников для
демонстрации экрана, затем выходит. `COMS_TEST_BLOCK` — список хостов через
запятую, которые считаются недоступными (проверка переключения на запасной вход).

## Что ещё не сделано

- **Подпись кода.** Без сертификата Windows покажет предупреждение SmartScreen
  при установке. Нужен сертификат (~$100–300/год) и `signAndEditExecutable: true`.
- **Автообновление.** Нужен `electron-updater` + раздача сборок с сервера.
- **macOS-сборка.** Требует сборки на маке и Apple Developer ($99/год).
